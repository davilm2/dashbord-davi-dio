# dashbord-davi-dio
# 📊 Dashboard de Vendas de Assinaturas — PlayStation Plus

## 📌 Sobre o projeto

Este projeto consiste na criação de um **Dashboard de Vendas de Assinaturas** desenvolvido no Microsoft Excel, com o objetivo de organizar, analisar e visualizar dados relacionados a planos de assinatura.

O projeto foi desenvolvido como parte de um desafio da **DIO (Digital Innovation One)**, utilizando recursos do Excel para transformar dados brutos em informações relevantes para análise e tomada de decisão.

O dashboard apresenta informações sobre diferentes planos, tipos de assinatura, renovação automática e serviços adicionais, permitindo uma visão mais clara do comportamento das assinaturas e do faturamento.

## 🎯 Objetivos

* Organizar uma base de dados de assinantes;
* Analisar o faturamento das assinaturas;
* Comparar diferentes planos;
* Identificar o impacto da renovação automática;
* Analisar vendas de serviços adicionais;
* Criar indicadores para facilitar a interpretação dos dados;
* Desenvolver um dashboard visual e profissional no Excel.

## 🗂️ Estrutura da planilha

O arquivo está dividido em quatro principais abas:

### 🎨 Assets

Contém elementos visuais utilizados na construção do dashboard, incluindo:

* Paleta de cores;
* Elementos gráficos;
* Logos;
* Recursos visuais utilizados na interface.

A identidade visual utiliza principalmente tons de verde, buscando uma aparência inspirada na identidade visual do Xbox.

### 🗃️ Bases

Contém a base de dados utilizada nas análises.

Entre as principais informações estão:

* `Subscriber ID` — identificação do assinante;
* `Name` — nome do assinante;
* `Plan` — plano contratado;
* `Start Date` — data de início da assinatura;
* `Auto Renewal` — indicação de renovação automática;
* `Subscription Price` — preço da assinatura;
* `Subscription Type` — periodicidade da assinatura;
* `EA Play Season Pass` — contratação do EA Play;
* Informações relacionadas ao Minecraft Season Pass.

A base contém aproximadamente **295 registros de assinantes**, permitindo realizar análises e consolidações dos dados.

### 🧮 Cálculos

A aba de cálculos reúne as análises utilizadas para alimentar o dashboard.

Entre os indicadores analisados estão:

* Faturamento das assinaturas;
* Faturamento por renovação automática;
* Vendas do EA Play Season Pass;
* Vendas do Minecraft Season Pass;
* Distribuição das vendas por plano;
* Totais gerais das assinaturas.

Alguns dos resultados encontrados na análise incluem:

| Indicador                                        | Resultado |
| ------------------------------------------------ | --------: |
| Assinaturas trimestrais sem renovação automática |    R$ 806 |
| Assinaturas trimestrais com renovação automática |  R$ 1.502 |
| Total das assinaturas trimestrais                |  R$ 2.308 |
| EA Play Season Pass                              |    R$ 990 |
| Minecraft Season Pass                            |  R$ 1.140 |

### 📊 Dashboard

A aba principal do projeto apresenta o dashboard visual com o título:

**PLAYSTATION PLUS SUBSCRIPTIONS SALES**

O objetivo dessa área é transformar os dados e cálculos realizados anteriormente em uma apresentação visual mais simples de interpretar.

O dashboard permite analisar os principais indicadores relacionados às vendas e assinaturas.

O projeto permite responder perguntas como:

* Qual é o faturamento total das assinaturas?
* Quanto foi vendido em assinaturas com renovação automática?
* Quanto foi vendido em assinaturas sem renovação automática?
* Qual plano possui maior participação nas vendas?
* Quanto foi arrecadado com o EA Play Season Pass?
* Quanto foi arrecadado com o Minecraft Season Pass?

## 🚀 Como utilizar

1. Faça o download do arquivo `.xlsx`.
2. Abra o arquivo utilizando o **Microsoft Excel**.
3. Acesse a aba **Bases** para visualizar os dados utilizados.
4. Consulte a aba **Cálculos** para verificar as análises.
5. Acesse a aba **Dashboard** para visualizar os indicadores e resultados consolidados.
